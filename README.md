# AI-MatSci-Lab

An AI-powered Materials Science project that combines Machine Learning and Data Science techniques to analyze, predict, and visualize material properties. This repository is developed as part of academic research and learning in Artificial Intelligence for Materials Science.

## 📌 Features

- Data preprocessing and cleaning
- Exploratory Data Analysis (EDA)
- Machine Learning model training
- Material property prediction
- Model evaluation and visualization
- Jupyter Notebook implementation
- Easy-to-understand project structure

## 🛠️ Technologies Used

- Python 3.x
- Jupyter Notebook
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
- SciPy

## 📂 Project Structure

```
AI-MatSci-Lab/
│
├── data/                  # Dataset files
├── notebooks/             # Jupyter notebooks
├── models/                # Saved ML models
├── images/                # Figures and plots
├── requirements.txt       # Python dependencies
├── README.md              # Project documentation
└── main.py                # Main execution script
```

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/Varunkr07/AI-MatSci-Lab-varun.git
```

### 2. Navigate to the Project

```bash
cd AI-MatSci-Lab-varun
```

### 3. Create a Virtual Environment (Optional)

```bash
python -m venv venv
```

### 4. Activate the Environment

Windows

```bash
venv\Scripts\activate
```

Linux/macOS

```bash
source venv/bin/activate
```

### 5. Install Dependencies

```bash
pip install -r requirements.txt
```

### 6. Run the Project

```bash
python main.py
```

or open the Jupyter notebooks

```bash
jupyter notebook
```
